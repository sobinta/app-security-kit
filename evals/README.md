# Eval cases & sample apps

⚠️ **Everything under `evals/*/files/` is deliberately vulnerable. Never deploy it.** The "API keys" in the samples are fake and are generated by each `place-files.sh` at scaffold time, so no secret-shaped string is stored in this repository. Package manifests are kept as `package.json.fixture` so GitHub/Dependabot don't raise alerts for the intentionally outdated dependencies; the scaffold renames them.

| Case | Sample | What it checks |
|---|---|---|
| `fa-full-audit-golkhooneh` | Express + SQLite plant shop ("گلخونه") with all 27 problems planted, fake keys in the client and in git history, a public `backup.zip` | Full audit + fix in Persian: every fix verified by exploit-style checks, app still works, report lists what to rotate |
| `nextjs-supabase-audit-only` | Next.js 14 + Supabase + Stripe client portal: service_role behind `NEXT_PUBLIC_`, tables without RLS, public bucket, IDOR, unsigned webhook, open AI endpoint, committed `.env.local` | Audit-only mode: no code changes, prioritized report, all 27 steps, no full secrets printed |
| `fa-load-and-race-shop-api` | Dependency-free Node API with an event-loop-blocking endpoint, coupon and stock race conditions, and an unbounded in-memory log | Load/spike testing with numbers, race detection and fixes, capacity estimate, Persian report |

Each case folder follows the `claude plugin eval` layout: `prompt.md` (settings + the user's message), `case.yaml` (expected outcome + scaffold), `graders/` (one verifiable assertion per file), `files/` (the sample) and `place-files.sh` (scaffold).

## Use them
- **Self-tests (no AI):** `python3 tests/run_tests.py -v` scaffolds the samples into temp folders and checks the scanners.
- **Scaffold by hand:** `mkdir /tmp/try && cd /tmp/try && bash /path/to/app-security-kit/evals/fa-full-audit-golkhooneh/place-files.sh`, then ask Claude (with the skill installed) the prompt from `prompt.md`.
- **Claude Code eval runner (optional, real billed model runs):** from the repo root, `claude plugin eval . --allow-tools Write,Edit,Bash --scaffold`.
