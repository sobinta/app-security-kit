# VisaPortal

Client portal for an immigration & study consultancy (Next.js 14 App Router + Supabase + Stripe).

- Clients see their cases, consultant notes (markdown) and documents
- Staff dashboard at `/admin`
- Consultation payments with Stripe
- "Ask our visa assistant" (OpenAI) on the landing page

Setup: copy `.env.example` to `.env.local`, fill in Supabase/Stripe/OpenAI keys, `npm i`, `npm run dev`.
